# Learnings — Stage 3.1 (Strategy Brief)

**Auto-read** at stage start (Active Rules → gate input).
**Auto-written** at stage end (one Episode Log line, no user prompt).

## Active Rules

Rules producer applies as gate input at stage start. Pre-seeded from voice
canon + spec gates + v1.1-era lessons. New rules promoted here from Episode
Log only on user approval during pattern review.

- [SEED] Favor mechanism (the *why* it works) over phenomenon description (the *what* happens). Every chapter must answer "why does this work the way it does?"
- [SEED] Plan the Open Loop Hook (posed in first 30s, paid off in final 60s) at brief-writing time. Do not leave for Stage 3.2 to figure out.
- [SEED] Plan the Callback Number (a specific dollar/percentage figure introduced in chapter 1, re-referenced in final chapter) explicitly in the brief.
- [SEED] Pillar P1 (Why Everyone Gets X Wrong): Chapter 1 establishes the conventional/wrong assumption; Chapter 3 delivers the reframe; Chapter 5 delivers the mechanism.
- [SEED] Default to 7 chapters. Use 9 only if data density genuinely justifies the extra structure — extra chapters dilute retention.
- [SEED] Hidden-pattern angle must appear in the first 90 seconds of the planned voiceover, not in the last quarter.
- [SEED] Cap corporate examples per chapter at 2 unless each lands a distinct reframe. 4+ examples per chapter = padding.
- [SEED] Every datapoint requires VER (verified) / EST (estimate) / ATT (attributed) tag. Untagged data points = G1 binary fail.
- [SEED] Total datapoints across brief ≥ 80. Less than that = G1 binary fail.
- [SEED] Voice-script word target per pillar (from 01_overview):
    - P1: 1,150–1,300 words
    - P2: 1,300–1,450 words
    - P3: 1,150–1,300 words
    - P4: 1,350–1,500 words
    - P5: 1,000–1,150 words
