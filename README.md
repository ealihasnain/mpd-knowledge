# MPD Knowledge Base

Atomic reference files for the **MoneyPatternsDecoded** YouTube production
pipeline. Fetched live by the `mpd-producer` Claude skill at runtime —
edit any file, push, next stage invocation reads the new version.

## Quick links

- **Browse:** [https://ealihasnain.github.io/mpd-knowledge/](https://ealihasnain.github.io/mpd-knowledge/)
- **Index:** [00_index.md](00_index.md)
- **Spec:** v1.3 (chat-only architecture; daily cadence retired in favor of 3/week)

## How to update a file

1. Edit the `.md` locally.
2. Bump `version` in the YAML frontmatter, update `updated` date.
3. Add a one-line entry to `99_changelog.md`.
4. Commit and push:
   ```
   git add <file>.md 99_changelog.md
   git commit -m "<file>: <short description>"
   git push
   ```
5. Next `mpd-producer` invocation that fetches this file gets the new content
   automatically. The HTML viewer reflects on next page load.

## Structure

| Range | Purpose |
|---|---|
| `00–11_*.md` | Pre-stage references (universal or cross-stage) |
| `20–29_*.md` | Stage prompts (3.1 through 3.10) |
| `30–39_*.md` | Per-stage learning logs (auto-updated by producer) |
| `99_changelog.md` | Knowledge base version history |
| `queue.yml` | Active episode |
| `1_1c_calendar.yml` | Forward-looking calendar |
| `index.html` | Master HTML viewer (auto-fetches all .md) |
